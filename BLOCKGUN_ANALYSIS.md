## Conclusão e próximos requisitos
- O ZIP é uma extração/decompilação extensa, não um projeto Unity original pronto: o projeto editável exige cenas, prefabs, ProjectSettings, versão do editor e manifesto de pacotes.
- Os arquivos OBJ são malhas geométricas; verificar material, UV, rig, esqueleto e animações é necessário antes de usar personagens em jogo.
- Dados serializados e dump IL2CPP ajudam a reconstruir referências, mas não equivalem a cenas/prefabs restaurados.
- Para um APK próprio será necessário montar projeto Unity/Godot independente, reimplementar sistemas necessários e validar dependências/licenças.
- Multiplayer Photon: código cliente identificado, mas servidores, credenciais e compatibilidade de backend não foram confirmados.
